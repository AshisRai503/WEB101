# WEB101 P7: Reflection - React Data Visualization Dashboard

## Documentation: Concepts Applied

In this practical, I applied the following main concepts:

- Data visualization
- Reusable chart components
- Responsive charts
- External data file imports
- Chart.js component registration
- Date formatting with date-fns

These concepts helped me understand how the practical works beyond only copying the code. I was able to connect the theory from the report with the actual implementation steps.

## What I Learned

I learned how to use Data visualization, Reusable chart components, and responsive charts. I also learned that a working project depends on correct folder structure, correct package installation, and careful testing after every main change.

## Challenges Faced

- Registering Chart.js components correctly
- Choosing the right chart type for each dataset
- Making charts responsive inside dashboard cards

## How I Overcame the Challenges

- Kept each chart in a separate component.
- Used `ResponsiveContainer` for Recharts.
- Used responsive options in Chart.js.
- Checked the dashboard layout after each chart was added.

## Possible Future Improvements

- Add filters by month or category.
- Load data from an API instead of a static file.
- Add summary cards for totals and percentages.

## Final Reflection

This practical improved my understanding of data visualization in React. It also showed me the importance of writing organized code, testing each feature step by step, and documenting the work clearly in GitHub. The practical was useful because it connected classroom theory with real implementation work.
