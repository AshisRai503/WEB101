# WEB101 P1: Reflection - TikTok Frontend Clone using Next.js

## Documentation: Concepts Applied

In this practical, I applied the following main concepts:

- File-based routing in the Next.js app directory
- Reusable React components such as layout, video cards, and video feed
- Utility-first styling using Tailwind CSS
- Form state handling and validation using React Hook Form
- Basic navigation between frontend pages

These concepts helped me understand how the practical works beyond only copying the code. I was able to connect the theory from the report with the actual implementation steps.

## What I Learned

I learned how to use File-based routing in the Next.js app directory, Reusable React components such as layout, video cards, and video feed, and utility-first styling using tailwind css. I also learned that a working project depends on correct folder structure, correct package installation, and careful testing after every main change.

## Challenges Faced

- JSX syntax mistakes while building components
- Tailwind class conflicts affecting layout and button size
- Understanding validation patterns in React Hook Form

## How I Overcame the Challenges

- Checked component structure carefully and fixed JSX closing tags.
- Adjusted Tailwind utility classes step by step.
- Tested form validation repeatedly and compared it with the expected behavior.

This practical improved my understanding of frontend development and full-stack connection.
