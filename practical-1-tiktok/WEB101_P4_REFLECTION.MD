# WEB101 P4: Reflection - Connecting TikTok Frontend to Backend

## Documentation: Concepts Applied

In this practical, I applied the following main concepts:

- Frontend-backend communication
- Axios instance configuration
- Request and response interceptors
- Token-based authentication on the frontend
- React Context for auth state
- Dynamic routing in Next.js

These concepts helped me understand how the practical works beyond only copying the code. I was able to connect the theory from the report with the actual implementation steps.

## What I Learned

I learned how to use Frontend-backend communication, Axios instance configuration, and request and response interceptors. I also learned that a working project depends on correct folder structure, correct package installation, and careful testing after every main change.

## Challenges Faced

- Explore users page initially showed 404
- Video feed failed when backend was not running
- Profile route showed user not found before dynamic route was fixed
- Keeping frontend and backend API paths consistent

## How I Overcame the Challenges

- Fixed file path and page route structure.
- Checked backend server port and API base URL.
- Created reusable service files to avoid repeated API code.
- Tested routes step by step after each fix.

## Possible Future Improvements

- Improve error messages in the UI.
- Add loading skeletons while API data is loading.
- Make search, likes, and upload flow more complete.

## Final Reflection

This practical improved my understanding of frontend development and full-stack connection. It also showed me the importance of writing organized code, testing each feature step by step, and documenting the work clearly in GitHub. The practical was useful because it connected classroom theory with real implementation work.
